NovelAI Image Generation

Generate, refine and inpaint images with NovelAI from a Krita docker.

Setup

  1. Open Settings → Dockers → NovelAI.
  2. Click Settings in the docker and paste a NovelAI Persistent API Token (novelai.net → User Settings → Account → Get Persistent API Token).

Modes

The mode depends on the Strength slider and whether something is selected:

  • No selection, 100%: generate a new image the size of the canvas.
  • No selection, below 100%: refine the whole canvas (image to image).
  • Selection, 100%: inpaint the selection using the surrounding canvas as context.
  • Selection, below 100%: refine only the selected area.

Every result is added as a new layer above the active layer and kept in the history at the bottom of the docker. Double-click a thumbnail to add it again. Right-click it to save it to disk, reuse its seed or prompt, or remove it from the history. Saving writes the file exactly as NovelAI sent it, including the prompt and settings NovelAI embeds in the PNG.

The history is kept in memory only and is cleared when Krita closes.
