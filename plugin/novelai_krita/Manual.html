NovelAI Image Generation

Generate, refine and inpaint images with NovelAI from a Krita docker.

Setup

  1. Open Settings → Dockers → NovelAI.
  2. Click Settings in the docker and paste a NovelAI Persistent API Token (novelai.net → User Settings → Account → Get Persistent API Token).

Live preview

With V4 and newer models, each generation step is shown in a temporary NovelAI preview layer, which is replaced by the finished result (or removed if you cancel). Turn it off in Settings → Live preview.

Tag autocomplete

While you type in either prompt box, NovelAI suggests tags for the word at the cursor (free, no Anlas). Use Up/Down to choose, Tab or Enter to insert, Escape to close. Italic suggestions are fuzzy matches. Typing Japanese (e.g. 銀髪) suggests the English tag. It can be turned off in Settings.

Modes

The mode depends on the Strength slider and whether something is selected:

  • No selection, 100%: generate a new image the size of the canvas.
  • No selection, below 100%: refine the whole canvas (image to image).
  • Selection, 100%: inpaint the selection using the surrounding canvas as context.
  • Selection, below 100%: inpaint the selection at that strength, so more of the original survives (V4 and newer; V3 models refine it with image to image instead).

An inpainted layer contains exactly the pixels NovelAI changed. That can reach a few pixels past the selection, where NovelAI blends the new content into the original, the same as on the NovelAI site. To get NovelAI's whole image as the layer instead, turn on Inpainting: Add the whole image as the layer in Settings (the layer then covers everything below it).

Every result is added as a new layer above the active layer and kept in the history at the bottom of the docker. Double-click a thumbnail to add it again. Right-click it to save it to disk, reuse its seed or prompt, or remove it from the history. Saving writes the file exactly as NovelAI sent it, including the prompt and settings NovelAI embeds in the PNG.

The history is kept in memory only and is cleared when Krita closes.
